# Joel Jr. M. Jocoy — Portfolio Website

A responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Files
- `index.html` — page content
- `style.css` — layout, colors, and responsive styling
- `script.js` — mobile navigation and footer year
- `profile.jpg` — optional portrait image

## Add your profile photo
Place your chosen portrait in this folder and rename it exactly `profile.jpg`. The page shows a simple initials placeholder if no photo is present.

## Preview on a phone
Extract the ZIP, then open `index.html` using a browser or a local HTML preview app.

## Publish with GitHub Pages
1. Create a **public** GitHub repository (for example, `joel-jocoy-portfolio`).
2. Upload `index.html`, `style.css`, `script.js`, and optionally `profile.jpg` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then save.
6. Wait for deployment. Your site address will look like `https://YOUR-USERNAME.github.io/joel-jocoy-portfolio/`.

## Privacy note
This site intentionally leaves out date of birth, religion, civil status, and other personal details that are usually unnecessary on a public portfolio. Consider whether you want your phone number and email visible before publishing.
